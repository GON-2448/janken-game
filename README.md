# じゃんけんゲーム



PythonとTkinterを使って作成した、シンプルなじゃんけんゲームです。



## 機能



* グー・チョキ・パーを選択

* コンピュータがランダムに手を選択

* 勝ち・負け・引き分けを判定

* 試合数・勝敗数を表示

* スコアをリセット



## 使用技術



* Python

* Tkinter



## 起動方法



以下のコマンドを実行してください。



```bash

python じゃんけん.py

```



## ファイル構成



* `じゃんけん.py`：ゲーム本体

* `gu.png`：グーの画像

* `choki.png`：チョキの画像

* `pa.png`：パーの画像

* `README.md`：このプロジェクトの説明
